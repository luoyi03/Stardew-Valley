# ModManager（星露谷 Mod 管理器）

游戏内的 Mod 管理器：**检测已装 Mod 的新版本，并一键下载安装更新**。

- 项目源码：`src/`
- 已自动部署到：`E:\Steam\steamapps\common\Stardew Valley\Mods\ModManager`

---

## 怎么用

三种入口，任选：

| 入口 | 说明 |
| --- | --- |
| 按 **F9** | 游戏内随时打开（可在设置里改按键） |
| 控制台 `modmgr` | 其它几个命令见下 |

> 标题界面默认不再显示图标；想恢复的话在设置里把「标题界面显示入口按钮」打开。

控制台命令（SMAPI 控制台窗口里输入）：

```
modmgr             打开管理界面
modmgr check       后台检查一次，把可更新的 Mod 打到日志
modmgr update all  检查并更新全部可自动更新的 Mod
modmgr update <ID> 只更新某个 Mod，ID 用 manifest 里的 UniqueID，如 Pathoschild.TractorMod
```

## 第一次用：填 Nexus API Key

你装的 Mod 大部分只发布在 **Nexus Mods**，而 Nexus 的接口要求每个人用自己的 API Key（免费）。没填的话，Nexus 来源的 Mod 会显示「未填写 Nexus API Key」，无法检查和下载。GitHub 来源的 Mod 不需要任何 Key。

1. 浏览器打开 `https://next.nexusmods.com/settings/api-keys`（设置面板里有按钮可直接打开）
2. 登录 Nexus 账号 → 生成一个 API Key → 复制
3. 游戏里按 F9 打开管理器 → 右上角「设置」→ 点第一行输入框 → 键盘输入粘贴的内容 → 点「保存」

> 输入框只支持键盘输入（字母 / 数字 / `_ - .` 等），没有剪贴板粘贴。
> 用 Shift + `-` 可以打出下划线 `_`。

## 界面说明

- 顶部：**检查更新**、**设置**、右上角 × 关闭
- 第二排筛选：**全部 / 可更新 / 已最新 / 需手动**，右侧 **全部更新 (N)**
- 每一行：Mod 名 + `当前版本 → 最新版本 · 来源`，右侧两个按钮
  - **网页**：用浏览器打开 Mod 页面
  - **更新**：下载并替换（GitHub / Nexus 来源可用）；灰色表示需要手动更新
- 左键点行的空白处 = 打开该 Mod 所在文件夹
- 右键点行 = 忽略 / 取消忽略这个 Mod 的更新检查
- 更新时按钮位置会变成进度条

## 本地下载目录：把下好的包装进游戏

Nexus 对**免费账号**不开放下载接口（详情见下），所以主力用法是这个：

1. 设置 → 「**Mod 下载目录**」→ 填你放 Mod 压缩包的文件夹（可以点「粘贴」把路径粘进来），保存
2. 浏览器里把 Mod 下载到那个文件夹（zip 就行；已经解压好的 Mod 文件夹也可以直接放进去）
3. 游戏里 F9 打开管理器 → 点工具栏右边的「**安装下载包 (N)**」,一次全装完

安装时会自动：

- 读压缩包里的 `manifest.json` 认出 UniqueID
- **已装过的 Mod** → 定位到它原来的目录，先备份再覆盖
- **没装过的** → 在 `Mods\` 下新建目录装进去
- 装完把源文件移到下载目录下的 `_已安装` 子目录，不会重复安装
- 如果文件被占用，会排队到下次启动时补装

设置里打开「启动时自动安装下载目录」的话，以后开游戏就自动装，连按钮都不用点。

## 一键更新做了什么

1. 从 GitHub Release 或 Nexus 下载最新文件（zip 或 dll）
2. 解压到临时目录，自动找到里面 `manifest.json` 所在的那一层作为包根目录
3. **把旧版本整个目录备份**到 `Mods\.ModManager\backup\<ModID>\<时间戳>`（只保留最近 3 份，可在设置里关掉）
4. 用新文件覆盖旧文件（`config.json` 等本地文件会保留）
5. 完成后显示「已更新，重启游戏后生效」——**新版本要重启游戏才会加载**

如果替换时文件被占用（极少数情况），会自动暂存，并在**下次启动游戏时**补齐，界面底部会提示「N 个更新待下次启动应用」。

## 已知限制

- **Nexus 免费账号不能通过接口下载**：版本检测正常，但下载直链会返回 403（只有 Premium 才行）。
  这时按钮会变成「手动下载」，点了直接打开该 Mod 的 Files 页；配合上面的「本地下载目录」就能半自动完成。
- **ModDrop / CurseForge / Chucklefish** 来源没有公开的自动下载接口，只能显示版本状态并提供「网页」按钮手动更新
- **SMAPI 本体**会列在列表里用于提示新版本，但必须运行官方安装程序更新，不能一键替换
- 只支持 **zip** 包；`.7z` / `.rar` 只能手动
- 极少数压缩包里带中文文件名且不是 UTF-8 编码时，解压后文件名可能乱码（内容不受影响）
- GitHub 未登录时 API 限流是每小时 60 次，正常玩不会碰到；想放宽可以在设置里填 GitHub Token（可选）

## 数据位置

| 用途 | 路径 |
| --- | --- |
| 下载临时文件 | `Mods\.ModManager\temp` |
| 更新前备份 | `Mods\.ModManager\backup` |
| 待重启应用队列 | `Mods\.ModManager\pending.json` |
| 上次自动检查时间 | `Mods\.ModManager\lastcheck.txt` |

目录以 `.` 开头，SMAPI 不会把它当 Mod 加载。

## 设置项

| 项 | 默认 | 说明 |
| --- | --- | --- |
| Nexus API Key | 空 | 检测/下载 Nexus Mod 必需 |
| GitHub Token | 空 | 可选，提高 GitHub 限流额度 |
| 打开界面的快捷键 | F9 | 点一下再按新键即可改，Esc 取消 |
| 启动游戏时自动检查 | 开 | 有更新时会弹一条 HUD 提示 |
| 自动检查间隔（小时） | 12 | 避免频繁请求 |
| 更新前自动备份 | 开 | 建议保持开启 |
| 包含测试版（Beta） | 关 | 打开后会把 Beta 版也算作可更新 |
| 标题界面显示入口按钮 | 开 | 不喜欢可以关掉 |

配置文件仍保留在 `Mods\ModManager\config.json`，但建议一律用游戏内设置面板修改。

## 重新编译

```
cd f:\游戏空间\星露谷\ModManager
dotnet build -c Release
```

构建会自动复制 DLL 到游戏 Mods 目录，并在 `bin\Release\net6.0` 下生成发布 zip。
