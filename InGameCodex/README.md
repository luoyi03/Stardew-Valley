# InGameCodex —— 星露谷内置图鉴 & AI 问答 Mod

把「图鉴」和「攻略 AI」一起搬进游戏：物品的来源与用途、NPC 喜好、献祭进度、图鉴完成度随手可查，
条目可以直接拿进背包；碰到查不到的问题，按一下键直接问 AI，回答会带上你当前存档的状态。

## 按键

| 按键 | 作用 |
|---|---|
| `F6` | 打开 / 关闭图鉴面板 |
| `F5` | 直达「AI 问答」页（已经在 AI 页时再按一次则关闭面板） |
| `Esc` | 关闭面板（有二次确认框时则是取消） |
| `Tab` 或 `←` `→` | 在六个标签之间切换 |
| `↑` `↓` / `PageUp` `PageDown` / `Home` `End` | 滚动列表；物品 / NPC 页则是移动选中项 |
| `Enter` | AI 输入框里确认发送 |

按键可在 `config.json`（首次进游戏后生成）里改 `ToggleKey` 和 `Ai.AskKey`，
也可以在图鉴的 AI 页点设置按钮，在游戏内直接改。
两个键都做了「被 Mod 吃掉」的处理——按 `F5` / `F6` 不会同时触发游戏本身或其它 Mod 的操作。

## 六个标签页

| 标签 | 内容 |
|---|---|
| 物品 | 全部物品（12 类：物体 / 大型可制作物 / 工具 / 武器 / 家具 / 上衣 / 帽子 / 裤子 / 鞋子 / 饰品 / 人偶 / 壁纸地板），每条含来源与用途；支持中文名、英文名、代码搜索与类型筛选 |
| NPC 喜好 | 每位 NPC 的五档喜好（最爱 / 喜欢 / 普通 / 不喜欢 / 讨厌）+ 生日 + 是否可结婚 |
| 献祭进度 | 社区中心各收集包的完成情况，可只看「还差什么」 |
| 图鉴完成度 | 各项收集进度（每个分项显示 已收集 / 总数） |
| 收藏 · 最近 | 手动收藏的条目 + 最近查看过的条目（最多 50 条） |
| AI 问答 | 接入大模型自由提问，回答里出现的物品名 / NPC 名可点击，直接跳到对应条目 |

界面整体缩放可在 `config.json` 里改 `UiScale`（默认 1.4，文字、行高、图标一起放大）。

## 直接获取物品

物品条目详情里有「获取」按钮，点一下物品直接进背包（背包满了会掉在脚下）。
是否二次确认由 `ConfirmMode` 控制：

| 值 | 行为 |
|---|---|
| `Smart`（默认） | 数量为 1 且普通品质时直接给，否则弹确认框 |
| `Always` | 每次都确认 |
| `Never` | 从不确认 |

AI 那边也能给：`Ai.AiCanGiveItems` 打开后，AI 回答下方会出现「获取」按钮，点了才真的进背包。

## AI 配置

内置常见 OpenAI 兼容接口的预设，一键切换地址与模型：

| 预设 | 接口 |
|---|---|
| 魔芋 / 美团 LongCat / 智谱 GLM / 硅基流动 / DeepSeek 官方 / OpenAI / 火山方舟豆包 | 各家云端 API |
| 本机 DSH 网关 | 启动时自动读取 `~/.dsh/.trio-shim.json`（端口和密钥每次启动都会变，Mod 会自动刷新） |
| 本地 Ollama / 本地 LM Studio | 免费离线，不需要密钥 |
| 自定义 | 自己填地址、模型、密钥 |

在 AI 页点设置按钮打开设置面板，可改：

- **接口地址 BaseUrl / 模型 Model / 密钥 ApiKey**——密钥按方案分别记住，切换方案时自动带出
- **采样参数**：Temperature、MaxTokens、TimeoutSeconds、Stream（流式输出）、MaxHistory（保留几轮上下文）
- **内容增强**：是否附带当前存档状态（季节 / 日期 / 天气 / 技能 / 背包等）、是否检索本地教程、
  是否用本图鉴的物品与 NPC 索引作为回答依据（可调各自注入字数上限）
- **额外系统提示**：比如要求「回答一律用粤语」
- **省积分模式**：一键压低上下文轮数、关闭教程注入、压低回答上限
- **快捷提问按钮**：AI 页下方那排一键提问，内容可用 `|` 分隔自定义
- 打开 AI 问答的按键、滚轮方向反转

首次启动时，如果本 Mod 的密钥还是空的、而 `Mods\StardewAI\config.json` 存在，
会自动把 StardewAI 的接口设置复制过来当默认值（只做一次，且只读不写对方配置）。

AI 输入框支持中文输入法（带候选框定位处理），可以直接打中文提问。

## 控制台命令

SMAPI 控制台（游戏窗口）里可以直接用：

```text
codex                打开图鉴面板（物品页）
codex 物品|npc|献祭|图鉴|收藏|ai     打开指定标签页
codex index          打印索引统计：条目数、各类型条数、反向索引、构建耗时与告警
```

## 目录结构

```text
InGameCodex/
  InGameCodex.csproj     # 项目文件（GamePath 指向游戏目录，构建后自动部署到 Mods）
  manifest.json          # SMAPI 清单（UniqueID: ly.InGameCodex）
  src/
    ModEntry.cs          # 入口：按键、控制台命令、配置落盘
    ModConfig.cs         # 图鉴本体的配置
    Ai/                  # AI 问答：接口客户端、会话、预设、教程检索、设置模型
    Data/                # 索引：物品、来源 / 用途反向索引、NPC 喜好、献祭与图鉴进度
    Ui/                  # 面板绘制与交互（六个标签各一个分部类）
  assets/
    pinyin.json          # 拼音检索数据
  tools/
    extract_pinyin.py    # 由物品名生成拼音检索数据
```

## 编译

需要 .NET SDK（可编译 `net6.0`）与 SMAPI 4.0+：

```powershell
cd e:\星露谷\InGameCodex
dotnet build -c Release
```

`InGameCodex.csproj` 里的 `GamePath` 指向游戏安装目录（当前为
`F:\steam\steamapps\common\Stardew Valley`），构建成功后会自动复制到
`Mods\InGameCodex`；若你的游戏不在该路径，改这一项即可。

## 已知取舍

- 英文名显示、界面缩放等属于全局外观设置，改完需要重开面板生效。
- AI 回答质量取决于所选模型；本地小模型（Ollama 7B 级）建议关掉「注入图鉴索引」以免上下文过长。
